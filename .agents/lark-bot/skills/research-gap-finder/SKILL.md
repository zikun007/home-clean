# research-gap-finder — 找研究空白

## 输入

- 一组论文（用户给链接、bridge 预取的素材、或已推送论文库）；
- 一个方向/问题，例如“multi-agent debate 还有什么没人做”。

## 流程

1. 先列出语料范围和覆盖度：读了几篇、哪些只有摘要、时间范围。
2. 建 taxonomy：按问题、方法、评测、假设分组。
3. 找三类 gap：
   - **覆盖空白**：某个重要 setting/数据/模态没人做；
   - **瓶颈**：多篇论文都承认但没解决的限制；
   - **争议**：结论互相矛盾、评测协议不一致。
4. 每个 gap 给出：
   - 证据（哪几篇、哪一节/哪张表）；
   - 为什么现在可以做（新模型/新数据/新算力）；
   - 最小验证实验（1-2 周能跑什么）；
   - 风险：可能只是“伪 gap”。
5. 明确区分“没人做”与“做了但没效果/没发表”。

## 硬约束

- 不许为了显得新颖而强行造 gap。
- 语料不足时必须说“可能因为阅读不全而是伪 gap”。
- 不编造“某篇论文没做 X”，除非确认过全文/附录；不确定就标“待核实”。
- 引用论文时给 arXiv 链接或标题。

## 输出结构

```markdown
# <方向> 研究空白分析

## 语料与覆盖
## Taxonomy
## Gap 1：...
- 证据：
- 机会：
- 最小验证：
- 伪 gap 风险：
## Gap 2：...
## 优先级建议
## 待核实
```
