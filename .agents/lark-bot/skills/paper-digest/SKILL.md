# paper-digest — 每日论文速递

## 输入

bridge 会提供：

- 当天候选包（Markdown，含标题、摘要、分类、Comment、Journal ref、规则分）；
- 关注方向（`topics.json`）；
- 要求的篇数区间（默认 4-8）。

用户也可能直接说“看看今天 cs.RO 有什么新论文”。

## 流程

1. 先读候选包，不要重新爬一遍 arXiv，除非候选为空或用户点名某个方向。
2. 用规则分做初筛，再判断：
   - 与主人方向的相关性（标题/摘要是否真的相关，不被单个热词带偏）；
   - 摘要是否具体（有没有明确的 claim、方法、实验）；
   - 质量信号：会议/期刊、Oral/Spotlight、开源代码、项目页；
   - 新颖性：是否只是已有工作的增量。
3. 需要核实会议、开源状态时可以联网搜索；**查不到就写“未知”**。
4. 最终选 **4-8 篇**，宁缺毋滥。候选不足 4 篇时如实说明，不要凑数。
5. **每天额外推荐 1 篇经典论文**（不计入上面的 4-8 篇）：
   - 运行：`python3 ~/.agents/papers/classics.py pick --date YYYY-MM-DD --json`
   - 脚本会随机抽取一篇往年高认可度论文，并记录已用列表，避免短期内重复；
     论文池用完会自动开始新一轮。
   - 把返回的 `paper` 写入速递的“经典论文推荐”章节；`why` 字段是人工整理的
     推荐理由，可以转述，但不要扩写成没有依据的实验结论。
   - 如果脚本报错或论文池为空，写“今日经典论文推荐暂缺”，不要临时编一篇。

## 输出格式（中文 Markdown）

```markdown
# 每日论文速递 YYYY-MM-DD

共 N 篇（不含经典论文）。今日关键词：...

## 1. 论文标题
- arXiv: https://arxiv.org/abs/XXXX.XXXXX
- 分类/发布：cs.RO · 2026-11-02
- 一句话结论：...
- 核心贡献：...
- 为什么值得读：...
- 质量依据：会议/期刊（或未知）；代码（或未知）；规则分 ...
- 阅读优先级：值得精读 / 值得速读 / 可暂缓

## 经典论文推荐
**标题**（作者，年份，venue）
- 链接：...
- 领域：...
- 为什么经典：...
- 和你方向的关系：...
```

末尾可加一段“今日趋势/观察”，但必须基于候选摘要，不得编造。

## 硬约束

- 不编造实验数字、数据集、SOTA、开源状态、会议录用状态。
- 区分“论文明确说”“合理推断”“未支撑”。
- 只基于摘要时标明“仅基于摘要判断”。
- 不推送明显不相关或纯 survey/review 的论文，除非用户明确要求。
- 经典论文每天只推 1 篇；不要用当天候选里的新论文冒充经典论文，也不要
  自行编造“高引用/经典”身份，只使用 `classics.py` 返回的池内论文。
- 最终把完整速递写入 bridge 指定的 `DIGEST_PATH`，并在答复末尾单独输出
  `DIGEST_PATH=<绝对路径>`。
