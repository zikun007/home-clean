# paper-deep-note — 单篇精读卡

bridge 会给出论文元数据、全文/摘要路径、笔记输出路径。优先读全文；没有全文时明确标注
“仅基于摘要判断”。

## 笔记模板

```markdown
# 论文标题

- arXiv: https://arxiv.org/abs/XXXX.XXXXX
- 作者/机构：
- 发布/会议：
- 代码/项目页：
- 阅读日期：
- 覆盖范围：全文 / 部分 / 仅摘要

## 1. 研究问题
论文要解决什么问题？为什么重要？此前方法卡在哪？

## 2. 核心主张（Claim）
用 1-3 句话写清楚。区分作者声称与证据支持。

## 3. 方法
- 关键思路：
- 模型/算法结构：
- 训练数据与目标：
- 关键假设：

## 4. 实验与证据
- 数据集 / 指标 / baseline：
- 主结果：
- 消融：
- 证据强度：强 / 中 / 弱（说明理由）

## 5. 关键图表
哪张图/表承载核心证据？它实际说明了什么？

## 6. 局限与失败模式
作者承认的 + 你从方法/实验中看出的。未验证的写“未知”。

## 7. 复现评估
- 代码/数据是否可得：
- 算力/数据成本：
- 最可能卡住的点：
- 是否值得复现：

## 8. 对主人方向的启发
能用到 open_nav / 机器人学习 / 导航 / 操作吗？给出 1-3 个具体切入点。

## 9. 待核实
列出没有证据或需要读附录/代码确认的点。

## 10. 阅读优先级
值得精读 / 值得速读 / 可暂缓
```

## 硬约束

- 不编造实验数字、数据集细节、消融结论、开源状态。
- 不确定的字段写“未知”，不要脑补。
- 每个关键结论尽量附“论文哪一节/哪张图表”。
- 笔记写入 bridge 指定的输出路径，并在答复末尾单独一行：
  `NOTE_PATH=<绝对路径>`。
- 最终答复给主人一段 200 字以内的摘要 + 笔记链接（若 bridge 已上传）。
