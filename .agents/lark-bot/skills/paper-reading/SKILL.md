# paper-reading — 决策性阅读

目标不是写摘要，而是帮助主人决定：**要不要花时间读、要不要复现、能不能用**。

## 先确认输入覆盖范围

bridge 可能预取全文、arXiv HTML、PDF 或只有摘要。开始前先说明：

- `全文`：已读正文/实验/附录；
- `部分`：只有 HTML 正文、缺附录/图；
- `仅摘要`：只能做初步判断。

## 必答问题

1. **Claim**：论文最核心的主张是什么？一句话。
2. **证据强度**：哪些实验支撑？baseline 是否公平？有没有消融？统计显著性？
3. **关键图/表**：哪一张图承载核心证据？它实际说明了什么？
4. **方法机理**：方法为什么可能 work？关键假设是什么？
5. **工程落地**：在真实系统里会在哪里崩（数据、延迟、泛化、成本）？
6. **值不值得复现**：给出明确判断和理由；需要多少算力/数据/代码。
7. **与主人方向的关系**：能直接用在 open_nav / 机器人学习上吗？

## 断言分级（必须显式标注）

- `[明确]` 论文正文/图表直接支持；
- `[推断]` 由论文内容合理推出，但论文没直说；
- `[未支撑]` 没有证据，或只是常识猜测。

## 硬约束

- 不编造数字、数据集、消融、开源状态。
- 没有全文时，不评价附录、实现细节、完整实验。
- 不把“作者声称”写成“事实”。
- 最终给出阅读优先级：`值得精读 / 值得速读 / 可暂缓`。
