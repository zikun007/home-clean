# AI C++ Coding 关键约束

你在生成或修改 C++17 代码时，必须遵守以下约束。优先保证安全、可维护、可静态分析；不要为了简短代码牺牲 MISRA 风险控制。

## 1. 函数复杂度硬约束

生成每个函数前，先按以下上限控制实现规模：

| 指标 | 上限 |
|---|---:|
| CCM | 15 |
| LEVEL | 5 |
| PATH | 1000 |
| CALLS | 30 |
| STMT | 100 |
| RETURN | 1 |
| GOTO | 0 |
| CYCLE | 0 |
| PARAM | 8 |

必须执行：

- 参数超过 8 个时，改用参数结构体或拆分接口。
- 嵌套可能超过 5 层时，先拆分函数或重构控制流。
- 分支、语句、调用数明显偏多时，优先拆成职责单一的小函数。
- 尽量使用单一出口；不要随手写多个 `return`。
- 禁止生成 `goto`。
- 禁止生成直接或间接递归。

## 2. 接口与返回值

生成函数签名前必须明确：

- 每个输入参数的含义、有效范围、所有权和生命周期。
- 指针参数是否允许 `nullptr`；能不用裸指针就不要用。
- 返回值语义和错误处理方式。
- 函数是否有副作用，例如修改参数、写状态、写日志、访问硬件或 I/O。

必须执行：

- 所有返回值必须被调用方使用或检查。
- 不生成未使用的命名参数。
- 不保存外部局部对象的指针或引用。
- 不返回局部变量、临时对象的指针或引用。
- 不引入全局变量或函数内 `static` 局部变量，除非用户明确要求并说明理由。

## 3. 控制流

必须生成结构化、可读、可分析的控制流：

- 所有 `if`、`else`、`for`、`while`、`switch` 代码块都必须使用 `{}`。
- `if ... else if` 链必须有最终 `else`。
- 非 `void` 函数必须保证所有路径返回值。
- 不生成不可达代码。
- `switch` 必须覆盖有效枚举/状态，并提供明确兜底策略。
- 循环必须有清晰终止条件；不要生成无限循环，除非用户明确要求。

## 4. 类型转换与指针

不要用“能编译就行”的转换。必须避免：

- C 风格转换：`(T)x`。
- 函数式转换作为类型转换：`T(x)`。
- `reinterpret_cast`。
- 移除 `const` 或 `volatile` 的转换。
- 整数、枚举、`void*` 到对象指针的随意转换。
- `0` 或 `NULL` 表示空指针。
- `bool` 与整数之间的隐式转换。
- 无关指针之间的大小比较或减法。

必须执行：

- 空指针只使用 `nullptr`。
- 必须转换时，优先使用语义明确且安全的 `static_cast`，并保证转换不会改变符号性、范围或对象语义。
- 数组参数优先使用项目已有 span/array/view 类型；没有时也要明确长度和边界。

## 5. 生命周期与资源

必须使用明确的生命周期和 RAII：

- 变量声明时初始化，作用域尽量小。
- 动态资源必须由 RAII 对象、容器或智能指针管理。
- 不生成裸 `new/delete` 所有权逻辑。
- 不访问生命周期已结束的对象。
- 不把短生命周期对象地址赋给长生命周期对象。
- `std::move` 只用于非 `const` 左值；move 后对象不得继续读取业务值。
- 转发引用必须与 `std::forward` 配套使用。

## 6. 禁用写法和库

除非用户明确要求处理历史代码，否则不要新增以下内容：

- 函数式宏。
- `asm`。
- `union`。
- `system`。
- `offsetof`。
- `atof`、`atoi`、`atol`、`atoll`。
- C 字符串处理函数。
- C 字符处理函数。
- C 库 I/O 函数。
- `memcpy`、`memmove`、`memset`。
- `<cstdarg>`、`<csetjmp>`、`<csignal>` 相关功能。
- `setlocale`、`std::locale::global`。

如果必须兼容已有代码中的上述内容，先说明风险和替代方案，再给出最小改动。

## 7. 类、继承与异常

生成类相关代码时必须遵守：

- 单参数构造函数和转换运算符必须加 `explicit`。
- 重写虚函数必须使用 `override`。
- 不隐藏基类函数。
- 不重载 `&&`、`||`、取址运算符 `&`。
- 特殊成员函数优先遵循 Rule of Zero；如需自定义，必须成组考虑拷贝、移动、析构语义。

生成异常相关代码时必须遵守：

- 不抛出或捕获指针类型异常。
- 类类型异常使用引用或 `const` 引用捕获。
- `noexcept` 函数不得传播异常。
- 构造/析构函数中的异常处理不得访问已失效或未构造完成的非静态成员。
